## Escenario elegido

## Descripción del proyecto
Este proyecto analiza datos simulados de ventas comerciales para obtener indicadores básicos de gestión empresarial.

El objetivo es aplicar herramientas de planificación, control de versiones, trazabilidad y análisis de datos en un flujo de trabajo organizado con Jira, Git, GitHub y Google Colab.

## Estructura del repositorio

- `/datos`: contiene el dataset `ventas.csv`.
- `/scripts`: contiene el script `analisis_ventas.py`.
- `/resultados`: contiene el resumen de indicadores y el gráfico generado.
- `.gitignore`: evita subir archivos temporales o innecesarios.
- `README.md`: documenta el proyecto.

## Indicadores calculados

- Ventas totales.
- Producto más vendido.
- Cantidad vendida del producto más vendido.
- Evolución mensual de ventas.

## Herramientas utilizadas

- Jira para planificación y seguimiento.
- Git para control de versiones.
- GitHub para repositorio remoto y Pull Requests.
- Google Colab como entorno de ejecución.
- Python, Pandas y Matplotlib para análisis de datos.
